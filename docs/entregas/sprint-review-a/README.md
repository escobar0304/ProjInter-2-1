## Conteúdo

A apresentação resume o percurso de aprendizagem, requisitos, use cases, modelos de domínio e relacional, arquitetura, consentimento, métricas, mapa das 16 User Stories, próximas etapas e balanço da Sprint A.

O mapa regista responsáveis, estados e percentagens declaradas para cada User Story. Os 100% assinalam uma issue fechada; N/D indica que não há percentagem registada. A A013 e a A016 estão fechadas. A referência do mapa é 27/11/2026.

O slide 8 mostra os resultados dos dados fictícios da A016: médias de 52,6% no diagnóstico e 73,3% no Final, ganho absoluto médio de 20,6 p.p. e ganho normalizado médio de 0,37. Estes valores não representam utilizadores da plataforma.
